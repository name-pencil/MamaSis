마마시스(まましす) 한글 패치

1. 게임을 종료합니다.
2. MamaSisPatch.exe를 Mamashisu.exe가 있는 게임 폴더에 넣습니다.
3. MamaSisPatch.exe를 실행하면 원본을 백업하고 같은 폴더에 패치합니다.
4. 완료 후 같은 폴더의 MamaSisKoreanLauncher.exe로 게임을 실행합니다.

실행 중 필요한 파일은 임시 폴더에 자동으로 풀리고 종료 시 정리됩니다.
현재 게임 폴더의 세이브를 그대로 사용합니다.
DLC가 있으면 함께 패치합니다. 글꼴은 게임 실행 중에만 등록합니다.

원본 복구
게임을 종료하고 MamaSisPatch.exe를 다시 실행한 뒤 1: 원본 복구를 선택합니다.
교체 전 파일을 복원하고 패치가 새로 추가한 런처·DLL·폰트는 제거합니다.
설치 전에 같은 이름의 파일이 있었다면 삭제하지 않고 원래 파일로 복원합니다.
세이브는 설치·복구 모두 수정하지 않습니다.
MamaSisPatch-backup.zip을 삭제하면 자동 복구할 수 없습니다.
복구가 완료되면 이 ZIP은 제거되며, 다시 패치할 수 있습니다.

오류가 나면
- 게임 폴더가 맞는지, 게임이 종료됐는지 확인하세요.
- 백업이 남아 있으면 다시 실행해 원본 복구를 선택하세요.
- 복구가 실패하면 백업 ZIP을 지우지 말고 오류 원인을 해결한 뒤 다시 복구하세요.
- 상세 생성 기록은 게임 폴더의 MamaSisPatch.log에 있습니다.

지원 환경: Windows 10/11 64비트와 검증 대상 원본 게임 파일.

설치 경로
한글·일본어·영어 폴더에서 사용할 수 있습니다. 경로 입력 없이 EXE 옆 게임 폴더를 찾습니다.
